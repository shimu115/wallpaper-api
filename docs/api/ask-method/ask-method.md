# API 请求方式

| 请求方式 | 接口 | 描述 |
| --- | --- | --- |
| GET | /acg/wallpaper/random | [随机acg图片](http://localhost:8080/api/acg/acg.html#随机acg图片) |
| GET | /bing/wallpaper/today | [今日壁纸](http://localhost:8080/api/bing/bing.html#今日壁纸) |
| GET | /bing/wallpaper/random | [随机壁纸](http://localhost:8080/api/bing/bing.html#随机壁纸) |
| GET | /bing/wallpaper/fresh_data | [手动刷新数据](http://localhost:8080/api/bing/bing.html#手动刷新数据) |
| GET | /bing/wallpaper/getI18n | [获取可使用的语言数据](http://localhost:8080/api/bing/bing.html#获取可使用的语言数据) |
| GET | /bing/wallpaper/findPage | [分页查询数据](http://localhost:8080/api/bing/bing.html#分页查询数据) |
| GET | /bing/wallpaper/find | [查询数据](http://localhost:8080/api/bing/bing.html#查询数据) |
